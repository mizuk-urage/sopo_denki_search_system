# 学園祭 企画検索システム

電力シートなどの資料を登録して、企画番号・企画名・キーワード・テント番号などを検索する静的Webアプリです。初期状態は空で、例の企画やPDFは配布用アプリに含まれません。資料を追加すると企画ごとのページを作り、電力シート・配線図の該当ページを確認できます。スマートフォン・PCのブラウザーで動きます。

## 起動

データが空の検索画面をPCで確認するには `standalone.html` を開きます。端末から資料を登録する場合と、スマートフォンへホーム画面追加する場合は、GitHub PagesなどHTTPSのURLから開いてください。`data/data.json` を更新したときは `node build-standalone.js` で単体版も更新できます。

ホーム画面への追加とService Workerによるキャッシュを使う場合は、プロジェクトフォルダーで静的HTTPサーバーを起動してください。Pythonがある環境では:

```text
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。スマートフォンで使うには、同じWi-Fi内からアクセスできる端末でサーバーを起動し、HTTPSで公開してください。スマートフォンでは対応ブラウザーのインストールボタン、またはブラウザーの共有・メニューからホーム画面に追加できます。

GitHub Pagesへ公開した後は、スマートフォンで公開URLを開きます。Androidなど対応ブラウザーでは画面に「アプリをインストール」ボタンが表示された場合に押します。iPhone/iPadではSafariの共有メニューから「ホーム画面に追加」を選びます。OSの確認操作は必要です。

## データの初期状態

`data/data.json` は空の初期データです。アプリを公開した後、利用者が「資料・登録状況」から電力シートPDFを登録すると、その端末に企画ページが作られます。以前の会話で使ったサンプル資料は配布用アプリとは別の `C:\Users\4927c\Documents\sopo_search_system_test_samples` に保管しています。

## ファイル

- `app.js`, `index.html`, `styles.css`: 検索・表示。通常のデータ更新では触りません。
- `standalone.html`: `data/data.json` を内包した、サーバーなしで開ける版。データ更新後に `node build-standalone.js` で再生成します。
- `data/data.json`: 企画データ（更新対象）。
- `data/`: 公開する共通企画データ。初期状態では企画0件です。共通PDFを配布する場合は `data/pdfs/` に置き、JSONの `references` に登録します。
- `pdf-import.js`, `vendor/pdfjs/`: オフラインの電力シート抽出部品と日本語フォント・文字コード表。
- `icons/`: PC・スマートフォンのホーム画面に追加するためのアイコン。
- `service-worker.js`, `manifest.webmanifest`: オフライン保存とホーム画面インストール。
- `DESIGN.md`, `DATA_FORMAT.md`, `MAINTENANCE.md`, `DISTRIBUTION.md`, `AI_HANDOFF.md`: 設計・データ形式・保守・配布・AI引継ぎ。
- `tests/search.test.js`: 検索ルールの基本テスト。

## テスト

```text
node tests/search.test.js
node tests/pdf-import.test.mjs
```

## オフライン利用

**PC・スマートフォンとも、最初に一度オンラインで開いて保存が完了すれば、以降はオフラインで使えます。** スマートフォンと、アップロード資料もオフライン保存したいPCでは、HTTPSで公開したURLをSafari（iPhone/iPad）、Chrome（Android）、またはChrome/Edge（Windows/macOS）で開いてホーム画面／アプリに追加してください。Service Workerが画面・企画データ・参照PDFを保存します。保存が終わる前に接続を切らないでください。PCでZIP内の `standalone.html` を直接開く方法は、企画検索と同梱PDF閲覧向けです。ブラウザーの制約により、アップロード保存にはインストール済みアプリを使ってください。

画面から追加した4枠のPDFと企画ページは、その端末・ブラウザーのIndexedDBに保存するため、保存後はそのブラウザーでオフライン検索できます。ほかのブラウザーや端末には同期されません。文字情報のあるPDFは本文も検索対象になります。データや同梱PDFを更新したら `service-worker.js` のキャッシュ名末尾を変更し、利用者に一度オンラインで再読み込みしてもらいます。

電力シートPDFはPDF.jsを使って端末内で読み取り、企画番号・企画名・団体名・場所・許可電力・出典ページを候補として作ります。企画一覧ファイルは不要です。読み取り結果は登録前に確認・修正できます。企画ごとに、そのページから次の企画の直前までを参照ページとして個別ページに表示します。文字情報が入っていないスキャンPDFからのOCRは行いません。配線図PDFは同じエリア属性で登録すると各企画ページの関連資料に表示します。

## 資料の追加・差し替え

4つの登録枠は「資料・登録状況」タブに表示されます。各枠の現在のファイル名を確認し、同じ枠のボタンからPDFを選んでください。置き換えの確認後、配線図はすぐに差し替わり、電力シートは企画情報を確認して登録すると差し替わります。登録ファイルと企画ページはこのブラウザーだけに保存されます。

## 資料を追加して探す

資料本文のキーワード検索欄では、4枠に登録したPDFを検索できます。電力シートは企画情報を抽出し、確認・修正して企画ごとのページにします。スキャン画像だけのPDFはOCRしません。

追加ファイルはIndexedDBを使って登録したブラウザーの端末内に保存されます。サーバーへ送信されず、同じURLを使う他の人・他の端末とも共有されません。複数人で同じ資料を使う場合は、資料を `data/pdfs/` などの公開フォルダーに置き、企画データの `references` に登録して配布してください。追加ファイルはブラウザーの保存領域を使うので、容量の大きいPDFを多数登録する用途には向きません。
